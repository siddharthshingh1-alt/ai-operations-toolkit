## Problem

When a flight is delayed, finding every affected booking and telling every affected agent is manual, slow, and easy to get wrong under pressure.

## Which JD requirement this proves

Identify operational bottlenecks and solve them using AI.

## Who Uses It

The operations team handling live disruption; travel-agent partners on the receiving end.

## AI Usage

Classifies incident severity, finds affected bookings, and drafts agent communication. A human approves before anything is sent.

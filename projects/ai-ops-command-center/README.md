## Problem

Operational state is spread across several tools, so nobody starts the day knowing what actually needs attention.

## Which JD requirement this proves

Collaborate cross-functionally to drive execution.

## Who Uses It

Operations leads starting their day; anyone wanting one view of operational health.

## AI Usage

Generates a daily Ops Brief from the other projects' outputs. It aggregates and links back to sources — it is not a new source of truth and duplicates no logic.

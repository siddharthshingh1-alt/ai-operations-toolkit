## Problem

The operations inbox mixes booking changes, delay alerts, vendor mail, and finance queries. Urgent items get buried and threads go unanswered.

## Which JD requirement this proves

Build AI-assisted automations.

## Who Uses It

Operations associates triaging the shared inbox.

## AI Usage

Classifies incoming mail, flags urgency, summarizes long threads, extracts tasks, and drafts replies. Sending always requires explicit human approval.

## Problem

Operational data arrives as spreadsheets. Reading them takes hours, and the interesting movements are the ones nobody thought to look for.

## Which JD requirement this proves

Build dashboards; analyze operational data and identify improvement opportunities.

## Who Uses It

Operations associates and leads reviewing weekly performance.

## AI Usage

Column roles are inferred deterministically (type inference and name heuristics) and trends and anomalies are detected statistically. AI is used only to explain findings, always separating what was observed from what is merely hypothesised.

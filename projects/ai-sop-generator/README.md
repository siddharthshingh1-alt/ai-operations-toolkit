## Problem

Operational knowledge lives in people's heads and scattered chat threads. New joiners repeat mistakes, and processes drift because nobody rewrites the doc.

## Which JD requirement this proves

Document and standardize scalable operational processes.

## Who Uses It

Operations leads writing SOPs; the whole ops team searching them.

## AI Usage

Generates a structured SOP from a rough description, and answers questions over the SOP library using pgvector embeddings — always citing which SOP supports the answer, and saying so explicitly when nothing relevant exists.
